Consegna

Nested loops where the inner loop limit grows with the outer counter: row 1 prints 1, row 2 prints 1 2, etc. The inner loop runs i times on row i.

  • Key difference from rectangle: inner loop goes j <= i, not a fixed limit
  • The triangle shape emerges purely from the variable inner limit
  • Visualising nested loops: draw a table — row index = outer, column index = inner
