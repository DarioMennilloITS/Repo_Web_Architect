Rettangolo di Asterischi

Consegna

Stampa un rettangolo di asterischi usando for annidati.
Esempio con righe = 4 e colonne = 6:

******
******
******
******

Dimensioni rettangolo

Output:

-

Two nested for loops: the outer loop counts rows, the inner loop counts columns. Each inner iteration appends '*' to a row string; after the inner loop finishes a row, ' ' is appended.

  • Nested loops = 2D iteration: outer = rows, inner = columns
  • The inner loop runs cols times for every single outer iteration
  • Accumulate into a string, wrap in <pre> to preserve whitespace/newlines
