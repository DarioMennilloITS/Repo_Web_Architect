P2-ES5 - Giudizio Voto

Consegna

Usa switch per convertire voto numerico in giudizio:
10-9: Ottimo | 8-7: Buono | 6: Sufficiente | <6: Insufficiente

Inserisci il voto

Giudizio:

-

A switch on the vote value (1–10) maps each integer to an Italian judgment string. Values outside range are caught by default. Uses parseInt() to ensure integer comparison.

  • Integer switch is clean for small, known value sets
  • Out-of-range values are silently handled by default
  • parseInt() vs parseFloat(): use int when decimals are irrelevant
