Numero estratto:

-

Generates a random index with Math.floor(Math.random() * array.length), then accesses that index. Math.random() returns a float in [0, 1); multiplying by length and flooring gives a valid index.

  • Math.random() never returns exactly 1, so the index never overflows
  • Math.floor() rounds down — always a whole number
  • This is the standard pattern for random array selection in JS
