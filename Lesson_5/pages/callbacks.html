Demonstrates callback functions — functions passed as arguments to other functions. This pattern enables powerful operations like map, filter, and reduce on arrays.

  • A callback is a function passed as an argument to another function
  • map() transforms each element using a callback
  • filter() keeps elements where callback returns true
  • reduce() accumulates values using a callback
  • Method chaining: array.map().filter() creates pipelines
