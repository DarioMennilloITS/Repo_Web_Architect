Closure

Una closure è una funzione che ricorda l'ambiente in cui è stata creata, anche quando quell'ambiente non esiste più. È uno dei concetti più potenti di JavaScript.

1. Counter Privato

Una closure può creare variabili "private" che persistono tra le chiamate. Il counter non è accessibile dall'esterno, ma i metodi possono modificarlo.

Prova il Counter

0
function createCounter() { let count = 0; // ← questa variabile "vive" nella closure return { increment: () => ++count, decrement: () => --count, getValue: () => count }; }

Cos'è una Closure?

  • Una funzione che ricorda il suo scope
  • Ha accesso a variabili dell'ambiente esterno
  • Crea vere private variables in JS
  • Permette di "nascondere" implementazioni

Pattern Comuni

  • Module Pattern — Incapsulamento
  • Factory Functions — Funzioni generatrici
  • Data Encapsulation — Dati privati
  • Callback con stato — Event handlers

Sintassi Chiave

function outer() { let x = 10; // variabile privata function inner() { // ha accesso a x! return x++; } return inner; }

Quando Usarle?

  • Quando serve mantenere stato privato
  • Per creare funzioni configurabili
  • Nel module pattern prima di ES6
  • Negli event handler che ricordano dati
