Array to String

Consegna

Scrivi un programma per trasformare un array di elementi (stringhe) in un'unica stringa. Utilizza tutti i metodi che conosci.

Array di esempio

Array: ["Ciao", "mondo", "da", "JavaScript"]

Risultato:

-

Demonstrates three equivalent approaches: Array.join(sep) (built-in), a for loop that concatenates with a guard on the last element, and reduce() with an accumulator.

  • join() is idiomatic and fastest — use it in real code
  • The for-loop version shows what join does internally
  • reduce((acc, curr, i) => ...) — i === 0 skips the separator on the first element
