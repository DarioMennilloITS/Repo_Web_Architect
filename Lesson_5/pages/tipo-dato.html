Esempi Predefiniti

JavaScript ha tipi dinamici. Usa typeof per la maggior parte dei tipi, ma attenzione: typeof null restituisce "object" (bug storico)!

  • typeof "text" → "string"
  • typeof 42 → "number"
  • typeof true → "boolean"
  • typeof {} → "object"
  • typeof null → "object" (bug!)
  • Array.isArray([]) → true
