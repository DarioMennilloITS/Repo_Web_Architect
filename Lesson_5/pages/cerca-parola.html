Trova la parola "clara" all'interno del seguente testo: "Java Lorem ipsum sit dolor Java aliqua clara et pulcra sunt Java". Quando la trovi stampa la parola, altrimenti stampa: "parola non trovata".

Testo

"Java Lorem ipsum sit dolor Java aliqua clara et pulcra sunt Java"

Risultato:

-

Converts both the text and the search term to lowercase with .toLowerCase(), then uses .includes() (or indexOf()) to check presence. Returns position or boolean.

  • .includes() returns true/false — cleaner than checking indexOf !== -1
  • indexOf returns -1 when not found — the historical pattern
  • Always normalise case before comparing strings
