Demonstrates advanced callback patterns — asynchronous operations, error-first callbacks, array methods (find, some, every), and the evolution from callback hell to promises.

  • setTimeout/clearTimeout — execute once after delay
  • setInterval/clearInterval — execute repeatedly
  • Error-first callbacks: (error, result) => {} pattern
  • find() — returns first element matching condition
  • some() — returns true if ANY element matches
  • every() — returns true if ALL elements match
  • Callback hell: nested async calls become unreadable
  • Promises flatten async code with .then().catch()
