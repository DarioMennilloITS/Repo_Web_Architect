Numeri Palindromi

Consegna

Trova tutti i numeri palindromi da 1 a 1000.
Esempi: 121, 131, 454 (numeri che letti al contrario sono uguali).

Cerca palindromi

Intervallo: 1 - 1000

Trovati 0 palindromi:

Clicca il pulsante per cercare

For each number 1–1000: convert to string with .toString(), reverse by split('').reverse().join(''), compare with the original string. If equal → palindrome.

  • split('') turns a string into an array of characters
  • .reverse() mutates the array in place
  • .join('') collapses the array back to a string — this 3-step chain is the canonical JS palindrome check
