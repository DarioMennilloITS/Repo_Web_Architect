Parameters

Consegna

Crea una funzione che accetta parametri (nome, cognome, email, eta) e restituisce una stringa di saluto formattata. Implementa anche il recupero dei dati da input utente.

Registrazione Utente

Risultato:

-

Demonstrates function parameters — values passed into a function to customize its behavior. Parameters act as placeholders that receive arguments when the function is called.

  • Parameters are defined in the function declaration
  • Arguments are the actual values passed when calling
  • Functions can have multiple parameters separated by commas
  • Use template literals to interpolate variables into strings
