Somma Array

Somma gli elementi di due array allo stesso indice.

Somma per Indice

Istruzioni

Inserisci due array di numeri. La funzione sommera gli elementi allo stesso indice. Esempio: [1,2] + [3,4] = [4,6]

Risultato

Clicca il pulsante per calcolare...

Usa Math.max() per trovare la lunghezza maggiore, poi itera sommando elementi corrispondenti. Se un array e piu corto, usa 0.

  • Gestisci array di lunghezza diversa
  • Usa 0 per indici mancanti
  • Metodo map alternativo
  • Array.from per creazione dinamica
