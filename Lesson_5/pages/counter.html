Counter

A simple interactive counter with increment, decrement and reset functions.

Current Value

0

Min: -100 | Max: 100

A single count variable lives in the script's scope. Each button's click listener mutates it (±1 or reset to 0). After each mutation, the display is updated and boundary buttons are toggled disabled.

  • State lives in a JS variable — the DOM only reflects it
  • Disable buttons at boundaries to prevent invalid states rather than showing errors
  • button.disabled = true makes a button unclickable and greyed out
