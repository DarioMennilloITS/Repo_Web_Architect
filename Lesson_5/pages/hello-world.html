Hello World

Consegna

Scrivere un programma che chiede il nome all'utente per poi restituire un saluto in un tag <h1> del HTML.

Inserisci il tuo nome

Messaggio:

-

Reads the input value with .value, builds a greeting using a template literal (`Ciao, ${name}!`), then writes it into the DOM via innerHTML.

  • element.value always returns a string
  • Template literals use backticks and ${} for interpolation
  • innerHTML sets the HTML content of a node — use textContent when you don't need HTML tags
