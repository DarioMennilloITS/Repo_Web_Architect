Guess the Number

I am thinking of a number between 1 and 100. Can you guess it?

Number Guessing Game

Attempts: 0

Range: 1 - 100

Enter a number and click "Make Guess"

Previous Guesses:

No guesses yet

A target is set with Math.ceil(Math.random() * 100) once per game. Each guess compares the input to the target, increments an attempt counter, and gives high/low feedback. Win condition triggers a success message.

  • Math.ceil(Math.random() * 100) gives integers 1–100 (inclusive)
  • Binary search is the optimal strategy — halves the search space each guess
  • Attempt counting is just attempts++ on each submit
