Raddoppia fino a 1000

Consegna

Dato il numero let numero = 1; raddoppia la variabile numero finche non supera 1000, poi stampa il risultato.

Passaggi:

-

Uses a while loop because the number of iterations is unknown in advance. Each iteration doubles the value (val *= 2) and logs the step. Terminates when val > 1000.

  • Use while when you don't know how many iterations you need
  • *= 2 is shorthand for val = val * 2
  • Always ensure the loop condition will eventually become false — otherwise: infinite loop
