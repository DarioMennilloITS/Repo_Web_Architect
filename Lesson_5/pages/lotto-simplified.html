Lotto Simplified

Consegna

Estrai 5 numeri casuali tra 1 e 90, senza ripetizioni. Una sola estrazione per round.

Gioco del Lotto — Versione Semplice

Numeri estratti:

-

Builds an array of numbers 1–90. Picks 5 random indexes using splice() to remove each chosen number from the pool — this prevents duplicates without any extra checks.

  • splice(i, 1)[0] removes and returns the element — the pool shrinks each pick
  • Loop runs exactly 5 times — no while loop, no duplicate guard needed
  • Sort at the end is optional but makes the result easier to read
