Color Explorer

RGB: rgb(128, 128, 128)
HEX: #808080

Three range inputs (0–255) feed R, G, B values. Applied as rgb(r, g, b). Hex conversion: each channel is converted with n.toString(16).padStart(2, '0') and the three strings are concatenated.

  • input[type=range] fires input events continuously while dragging
  • Number.toString(16) converts decimal to hexadecimal string
  • padStart(2, '0') ensures single-digit hex values (like f) become 0f
